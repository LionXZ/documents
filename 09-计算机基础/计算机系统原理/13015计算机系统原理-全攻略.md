## 二、必考概念详解（按章）

> 每条概念给出三块内容：**① 定义详解**（讲清原理，可直接当名词解释/简答的答题素材）；**② 考试答题**（怎么考、答题模板、得分点、易错点）；**③ 计算方法**（计算类概念附步骤化模板 + 真题算例）。"必考"判定均附真题证据（考期×题型），与第三节真题汇编对应。

### 第 1 章 计算机系统概述

#### 1.1 冯·诺依曼结构与五大部件 ★★★

**定义详解**：冯·诺依曼计算机的核心是**存储程序（stored program）**工作方式——程序（指令序列）和数据预先存入存储器，计算机启动后由控制器按地址自动、逐条地"取指令→分析指令→执行指令"，直到程序结束。硬件五大部件：**运算器**（算术逻辑运算）、**控制器**（指挥协调）、**存储器**（存放程序和数据）、**输入设备**、**输出设备**。层级关系：运算器+控制器=CPU；CPU+主存=主机；输入/输出设备+外存=外围设备。

**考试答题**：
- 单选"工作方式的基本特点"→ 答存储程序（2024.10 单选 2）。干扰项"多指令流单数据流"是并行机分类，与工作方式无关。
- 填空"五大部件"→ 运算器、控制器、存储器、输入设备、输出设备，一个不能少（2025.4 填空 14）。
- 注意区分：**"完整的计算机系统"=硬件+软件**（2024.4 单选 1 选 B），而"冯·诺依曼结构"只讲硬件——两个题眼别混。
- I/O 设备辨析是 2026.4 新考法（单选 1、9 连考两题）：输入=扫描仪、数字化仪、键盘、鼠标、控制杆；输出=显示器、打印机、**绘图仪**。

#### 1.2 主频与 CPU 时间 ★★★

**定义详解**：主频是 CPU 时钟信号的频率，即一秒内的时钟周期数，单位 Hz（GHz=10⁹Hz）。时钟周期=1/主频，是 CPU 最小的时间单位。**CPU 时间（程序执行时间）= 指令条数 × CPI ÷ 主频**——三个因素共同决定，主频高不一定快。

**考试答题**：
- 名词解释模板（2024.10 名词解释"主频"，5 分）：一句话定义 + 单位 + 与性能的关系（"主频越高时钟周期越短，但性能还取决于 CPI 与指令条数"）。就三个得分点，缺一扣一。
- 简答"基本性能指标和 CPU 性能指标"（2026.4 简答 23）：分两层答——机器级：**字长、主频、存储容量**；CPU 级：**主频、CPI、MIPS、程序执行时间**，并写出 CPU 时间公式。

**计算方法**：
- 时钟周期 = 1/主频。例：500MHz → 1 个周期 2ns。
- CPU 时间 = 指令条数 × CPI ÷ 主频。例：10⁹ 条、CPI=2、主频 2GHz → 10⁹×2/2×10⁹ = 1s。
- MIPS = 指令条数 ÷ (执行时间×10⁶) = 主频 ÷ (CPI×10⁶)。

#### 1.3 CPI ★★★

**定义详解**：CPI（Cycles Per Instruction）= 执行一条指令所需的**平均**时钟周期数。不同指令类型周期数不同（访存慢、运算快），所以 CPI 是全部指令的加权平均：CPI = 总时钟周期数 ÷ 总指令条数。

**考试答题**：计算题必出（2024.10 计算题 27、2026.4 计算题 28 连续考）。题目给"A/B/C/D 四类指令的 CPI 与条数表"，四问固定套路（见下）。

**计算方法**（四步模板，务必列式）：
1. 总指令条数 N = 各类条数之和；
2. 总时钟周期数 = Σ(条数ᵢ × CPIᵢ)（逐类相乘再相加）；
3. 平均 CPI = 总周期数 ÷ N；
4. 执行时间 = 总周期数 ÷ 主频 = 总周期数 × 时钟周期。

例：A 类 2 条（CPI=1）、B 类 4 条（CPI=2），主频 500MHz → 周期数 = 2×1+4×2 = 10；N = 6；CPI = 10/6 ≈ 1.67；执行时间 = 10 ÷ 500MHz = 20ns。

#### 1.4 计算机系统层次结构与 ISA ★★★

**定义详解**：计算机系统是多层抽象：高级语言程序 →（翻译）→ 汇编/机器语言 → **ISA（指令集体系结构）** → 微程序/硬件数字电路。**ISA 是软硬件的分界面**：上面是软件（编译器、OS、应用），下面是硬件（数据通路、控制器）。ISA 的内容 = 指令集合 + 数据类型 + 寄存器 + 寻址方式 + I/O 控制方式等。

**考试答题**：
- 填空"ISA 层上面是____部分，下面是____部分"→ **软件；硬件**（2024.4 填空 12）。
- 单选判断"ISA 属于硬件级"→ 正确（2024.4 单选 4 选项 C）。
- 单选"ISA 设计追求的目标**不**包括"→ 选 CISC 化表述（增加指令复杂度不是目标；RISC 追求规整、简单、利于流水）（2025.4 单选 5）。
- 易错："指令集体系结构"≠"指令系统"本身，它还包括数据类型、寄存器、寻址方式等完整接口约定。

#### 1.5 软件分类与用户分类 ★★

**定义详解**：软件分**系统软件**（为使用和管理计算机提供服务：OS、编译器、汇编器、DBMS、文件系统等）与**应用软件**（解决具体应用问题）。固件 = 功能像软件、形态像硬件（固化在 ROM 中的微程序），体现"软硬件逻辑等价性"。用户分四类：**最终用户、系统管理员、应用程序员、系统程序员**。

**考试答题**：
- 定义型单选："介于硬件与应用程序之间……的软件"→ 系统软件（2024.4 单选 5）。
- 填空四类用户顺序：最终用户（终端用户）、系统管理员在前（2024.4 填空 13）。
- 易错：翻译程序（汇编/编译/解释）是系统软件；**链接程序不是翻译程序**（2024.4 单选 3）。

### 第 2 章 数据的表示与运算（计算题核心章）

#### 2.1 进制转换 ★★★（每卷第 1 题常客）

**定义详解**：计算机内部用二进制（器件两态易实现），人机界面用十进制/十六进制（十六进制是二进制的紧凑缩写，4 位二进制↔1 位十六进制）。

**考试答题**：单选给 3~4 个不同进制的数比大小/求某十进制数的二进制（2024.4 单选 2、2024.10 单选 1、2025.4 单选 1、2026.4 单选 3——**四次考期第 1~3 题全部是进制题**）。策略：全部统一化成二进制再比。

**计算方法**：
- 十→二（整数）：除 2 取余、逆序排列；更快的是**权值拼凑法**：192 = 128+64 = 2⁷+2⁶ = **11000000B**（2026.4 单选 3）。
- 二→十：按权展开：11000000B = 128+64 = 192。
- 二↔十六：从小数点起 4 位一分组：1100 0000 → C0H。
- BCD 码（8421 码）：每 4 位二进制独立表示 1 位十进制：0111 1000 1001 → **789**（2024.4 单选 2）。⚠️ 千万别按二进制权值展开（那是 1929，正是干扰项）。

#### 2.2 真值、机器数、原码/反码/补码 ★★★

**定义详解**：**机器数**=数及其符号在机器中的数字化表示（符号也用 0/1 编码）；**真值**=机器数代表的实际数值。n 位编码（最高位符号）：
- 原码：符号位+绝对值，0 有两种表示（+0/−0）；
- 反码：负数=原码数值位按位取反；
- **补码**：负数=反码末位+1（本质 = 模 2ⁿ − |x|），0 表示唯一，**符号位可与数值位一起参加运算，减法可化为加法**——这是补码运算系统的两大意义（2026.4 填空 12 两空正好考这两点）。

**考试答题**：
- 名词解释"机器数"（2026.4 名词解释 21，5 分）：定义（符号数值化）+ 与真值的关系。
- 简答"原码补码运算过程"（2026.4 简答 24）：分原码、补码两条线写——原码：符号位单独处理，同号绝对值相加，异号先比大小、大减小、符号随大数；补码：符号数值一起按模 2ⁿ 运算，减法化加（加 [−y]补），最高位进位自然丢弃。

**计算方法**（求补码三步）：
1. 写 |x| 的 n 位二进制；
2. x≥0 → 补码=原码，结束；x<0 → 全部位（含符号位）按位取反；
3. 末位 +1。

例：x = −68，8 位：68 = 0100 0100B → 取反 1011 1011 → +1 → **[x]补 = 1011 1100B = BCH**。
逆运算（补码→真值）：符号位为 0 直接读；为 1 → 取反加一得绝对值、添负号（或按权展开后减 2ⁿ）。
减法：[x−y]补 = [x]补 + [−y]补（[−y]补 = [y]补连同符号位一起取反加一）。

#### 2.3 溢出判定 ★★★

**定义详解**：运算结果超出机器数可表示的范围称溢出。**只有同号相加（或异号相减）才可能溢出**；异号相加永不溢出。溢出只对带符号数（补码运算）有意义。

**考试答题**：填空高频（2024.4 填空 14、2024.10 填空 15——两期连考）："同号数相加，当____超出 n 位数可表示范围时发生____"→ 结果（和）；溢出。分析题常与 CF/OF 一起考。

**计算方法**（三种判定法任选其一，建议都掌握）：
1. **符号比较法**（最常用）：正+正=负 或 负+负=正 → 溢出。
2. **双符号位法**（变形补码）：符号位 00/11 正常，01 正溢、10 负溢。两个符号位不同即溢出。
3. **进位法**：最高数值位向符号位的进位 ⊕ 符号位产生的进位 = 1 → 溢出。
- ⚠️ 区分 CF 与 OF：**CF=最高位产生的进位/借位（无符号数溢出），OF=带符号数溢出**，两者独立、互不相干。补码加法最高位进位被丢弃是模运算正常现象，不等于溢出（2024.10 分析题 29 考点）。

#### 2.4 浮点数表示：尾数与阶码 ★★★

**定义详解**：浮点数 = 阶码 × 尾数（类似科学计数法 N = 2^E × M）。**尾数位数决定精度，阶码位数决定表示范围**。基数与总位数一定时，阶码分得多 → 范围大但精度低，反之亦然（鱼与熊掌）。

**考试答题**：填空"尾数决定____、阶码决定____"→ 精度；范围（2024.10 填空 14 相关、2025.4 填空 13）。单选/判断考"扩大范围该加长谁"→ 阶码。

#### 2.5 浮点加减四步骤 ★★★（三次考期填空连考，全卷最高频考点）

**定义详解与计算方法**（四步口诀：**对阶 → 尾数加减 → 规格化 → 舍入**）：
1. **对阶**：求阶差 ΔE=Eₓ−Eᵧ；**小阶向大阶看齐**——阶小的尾数右移 |ΔE| 位、阶码加 |ΔE|（右移可能丢低位，损失的是小头）。⚠️ 绝不能大阶向小阶（尾数左移丢高位，灾难性错误）——填空年年考（2024.4 填空 15）。
2. **尾数加减**：对阶后两尾数按定点加减运算（含符号）。
3. **规格化**：结果不在 [1/2, 1)（补码规格化形式）时调整——尾数溢出（|M|≥1）则**右规**（尾数右移 1 位、阶+1）；有效位不以 1 开头则**左规**（尾数左移、阶−1），左规可能多次。
4. **舍入**：右移丢位后处理，常用"0 舍 1 入"。

算例：x = 2¹⁰×0.1100，y = 2¹¹×0.1000：
① 阶差 1，x 小 → x 尾数右移 1 位得 0.0110，阶变 2¹¹；
② 相加 0.0110+0.1000 = 0.1110；
③ 0.1110 已规格化；④ 无需舍入。结果 = 2¹¹×0.1110。

**考试答题**：填空考"4 步骤名称"（2024.10 填空 14）、考"对阶方向+右移的是谁"（2024.4 填空 15：小阶的尾数；移位位数=阶差绝对值）、考"缺的步骤名"（2025.4 填空 13：尾数加减）。简答则要求完整写出四步并说明对阶方向。

#### 2.6 ALU 与运算器组成 ★★★

**定义详解**：**ALU（算术逻辑运算单元）是运算器的核心部件**，完成算术（加减等）与逻辑（与或非等）运算；属组合逻辑电路。配套：暂存操作数的寄存器、移位器、多路选择器、标志寄存器（存放 OF/CF/ZF 等状态标志——标志不存放在 ALU 内）。数据通路中专门进行数据运算的部件统称**组合逻辑元件与时序逻辑元件**（组合输出仅由当前输入决定；时序含状态记忆，如寄存器）——2026.4 填空 16。

**考试答题**：单选"运算器核心部件"→ **ALU**（2024.10 单选 3、2026.4 单选 2——两期同考点）。干扰项加法器/移位器只是 ALU 的子部件。浮点运算器 = **阶码部件（只做加减）+ 尾数部件（加减乘除）**（2024.10 单选 4）。

### 第 3 章 程序的转换及机器级表示

#### 3.1 机器语言、汇编语言与翻译程序 ★★★

**定义详解**：机器语言=二进制机器指令；汇编语言=用**助记符、标号、寄存器名**等符号表示的、与机器指令**一一对应**的语言。翻译程序三种：**汇编程序**（汇编语言→机器语言）、**编译程序**（高级语言→目标代码）、**解释程序**（边翻译边执行）。反汇编 = 机器→汇编（逆向）。"用若干符号表示的、与机器指令一一对应的指令称为汇编指令"（2024.4 填空 11）。

#### 3.2 指令执行过程 ★★（2026.4 新增高频）

**定义详解**：CPU 执行一条指令的六个步骤：**取指令 → 指令译码 → 计算源操作数地址并取操作数 → 执行数据操作 → 计算目的操作数地址并存结果 → 计算下条指令地址**。

**考试答题**：填空挖两空：第 2 步"指令译码"、第 5 步"目的操作数地址"（2026.4 填空 17）。答题时按顺序背，注意"源操作数在前、目的操作数在后"。指令周期=取指周期+执行周期；取指结束后 PC 已指向下条指令。

#### 3.3 寻址方式 ★★

**定义详解**：寻址方式=寻找指令操作数有效地址的方式。常见：**立即寻址**（操作数在指令中）、**寄存器寻址**（操作数在寄存器）、**直接寻址**（地址在指令中）、**间接寻址**（地址在寄存器/主存单元中再取一次）、**寄存器间接**、**变址寻址**（形式地址+变址寄存器，适合处理数组）、**基址寻址**（面向操作系统重定位）、**相对寻址**（PC+偏移，用于转移指令）。

**考试答题**：单选"采用多种寻址方式的目的"→ **缩短指令长度、扩大寻址空间、提高编程灵活性**（2024.10 单选 5——完整背下这三点，干扰项"实现存储程序""降低译码难度"都不对）。判断各方式适用场景：数组循环→变址；程序浮动→基址/相对。

#### 3.4 寄存器分类：通用与专用 ★★★

**定义详解**：**通用寄存器**（EAX/EBX/ECX/EDX/ESI/EDI 等）可编程任意使用；**专用寄存器**各有唯一用途：**SP**（栈指针，指向栈顶）、**PC/IP**（指令指针，存下条指令地址）、**FP/EBP**（帧指针，界定栈帧）、标志寄存器（PSW）。

**考试答题**：单选"不属于通用寄存器的是"→ 在 SP/PC/BP/Flag 中选（2025.4 单选 4）。填空"SP 总是指向____"→ **栈顶元素**（2025.4 填空 15）。易错：SP 是专用不是通用。

#### 3.5 Intel 与 AT&T(GCC) 汇编格式 ★★★（分析题常客）

**定义详解**：两种汇编语法对照（必须逐条背）：
| 区别点 | Intel 格式 | AT&T(GCC) 格式 |
|---|---|---|
| 操作数顺序 | **目的在前** `mov dst, src` | **源在前** `mov src, dst` |
| 寄存器 | 直接写 `eax` | 加 % 前缀 `%eax` |
| 立即数 | 直接写 `10` | 加 $ 前缀 `$10` |
| 操作数长度 | `mov eax, ...`（寄存器名体现） | 指令加后缀 b/w/l（字节/字/双字） |
| 内存地址 | `[ebp+8]` | `8(%ebp)` |

**考试答题**：分析题给 Intel 指令序列，要求改写为 GCC 默认格式（2024.10 分析题 28）。答题四查：①先交换操作数顺序 ②寄存器补 % ③立即数补 $ ④按长度加 b/w/l 后缀。反向题同理。

#### 3.6 栈、栈帧与递归开销 ★★

**定义详解**：栈按"后进先出"原则操作，向低地址增长。**栈帧**=每次过程（函数）调用在栈中分配的一块区域，含返回地址、保存的寄存器、参数、局部变量，由 FP 与 SP 界定；调用结束栈帧释放。

**考试答题**：简答"递归调用的时空开销"（2024.10 简答 23）：空间——每层调用一个栈帧，额外空间 O(递归深度)，过深**栈溢出**；时间——每层都有 call/ret 与栈帧建立/拆除开销，且破坏 Cache 局部性，额外时间 O(n)。答题分"空间、时间"两段各写两点，最后加一句结论。

#### 3.7 C 语言相关考点 ★★（2026.4 新增）

**定义详解**：C 循环结构三种：**while、do-while、for**（do-while 先执行后判断、至少执行一次）。数组：`static short A[4];` 定义静态短整型数组；**数组名 A 代表首地址 = 第一个元素 A[0] 的地址**；数组按行优先连续存放，元素地址 = 首地址 + 下标 × 元素长度。

**考试答题**：填空两空："循环三语句缺 while 和 for"（2026.4 填空 14）；"static（静态）short 数组、首地址=第一个元素 A[0] 的地址"（2026.4 填空 15）。计算型填空/分析可能考"数组第 i 个元素的地址"：&A[i] = A + i×sizeof(short)。

#### 3.8 CISC 与 RISC ★

**定义详解**：CISC（复杂指令集计算机）：指令多、格式变长、多用微程序实现、单条指令功能强；RISC（精简）：指令少而规整、定长、大多数单周期完成、**Load/Store 结构**（只有访存指令访问存储器）、利于流水线。

**考试答题**：单选/判断考 RISC 特征（规整、简单、流水友好），干扰项常拿"增强单条指令功能、指令更复杂"混入——那是 CISC。

### 第 4 章 可执行文件的生成与加载执行

#### 4.1 源程序→可执行文件四步骤 ★★★

**定义详解**：**预处理 → 编译 → 汇编 → 链接**：
1. 预处理（cpp）：处理 #include/#define，宏展开，生成 .i 纯高级语言文件；
2. 编译（gcc）：.i → .s 汇编代码；
3. 汇编（as）：.s → .o **可重定位目标文件**（二进制，地址未定）；
4. 链接（ld）：多个 .o + 库 → **可执行目标文件**（地址确定）。

**考试答题**：单选"第一步"→ **预处理**（2024.10 单选 6，易错选"编译"）；单选"汇编语言→机器语言的一步"→ 汇编（2026.4 单选 6）。填空按序默写四个名词。

#### 4.2 链接与符号表 ★★★（2026.4 分析题新考法）

**定义详解**：链接器把若干可重定位目标文件与库组合成一个可执行文件，做三件事：**符号解析**（每个引用绑定到唯一定义）+ **重定位**（确定最终地址、修改引用）。可重定位目标文件中的符号三类：**全局符号**（本模块**定义**、可被其他模块引用的非静态函数与全局变量）、**外部符号**（本模块**引用**、定义在别处的符号，extern 声明）、局部符号（static，仅本模块可见）。

**考试答题**：
- 单选"可重定位目标文件→可执行目标文件的过程"→ 链接（2024.4 单选 6）。
- 简答"链接的好处"→ 模块化开发、代码复用（共享库）、便于维护更新；好处**不含**"缩短执行时间"（2025.4 单选 6 反向考）。
- 分析题考符号表归属（2026.4 分析题 30）：判断口诀——**本模块定义的函数名/全局变量名 = 全局符号；本模块只声明（extern）而未定义、用到了的 = 外部符号**。算例见 3.1 节第 30 题详解：main.o 全局符号 = buf、main，外部符号 = swap；swap.o 全局符号 = bufp0、bufp1、swap，外部符号 = buf。

#### 4.3 静态链接与动态链接 ★★★

**定义详解**：**静态链接**：链接时把库代码**复制**进可执行文件——文件大、内存中每个进程各带一份，但运行时不再依赖库；**动态链接**：链接推迟到**加载时或运行时**，可执行文件只记录引用信息，运行时把共享库**映射**进内存并绑定地址——内存中一份库代码多进程**共享**，库升级只需替换库文件。

**考试答题**：简答必背两特性（2024.10 简答 25 考"共享性与动态性"、2026.4 简答 26 考"两者差别"）：
- 共享性：一份库代码多个进程共享，省内存省磁盘；
- 动态性：链接时机推迟到加载/运行时才完成符号绑定（地址重定位）；
- 差别再补两点：库代码处理方式（复制 vs 映射）、更新维护（重新链接 vs 替换即生效）、动态链接有运行时开销。
答题按"时机、方式、共享、维护、开销"五维分条写，每条一行。

#### 4.4 重定位 ★★★

**定义详解**：把程序中的**逻辑地址调整为运行时的实际内存地址**的过程。三种时机：**链接时静态重定位**（地址在链接后写死，不能移动）、**加载时重定位**（装入时按起始地址统一修改，移动需重做）、**运行时动态重定位**（借助基址/重定位寄存器，程序运行中可移动，现代 OS 主流）。

**考试答题**：名词解释模板（2024.10 名词解释 21，5 分）= 一句话定义（"地址修改过程"必须出现）+ 两种以上时机 + 由谁完成（链接器/加载器）。三个得分点缺一不可。

#### 4.5 进程、fork/execve 与地址空间 ★★★

**定义详解**：**进程 = 程序的一次运行过程**（程序是静态文件，进程是动态实体，有独立地址空间与上下文）。每个进程用唯一正整数 **PID** 标识（2026.4 单选 7）。虚拟地址空间分为**内核空间与用户空间**两部分（2026.4 填空 19）。核心函数：**fork**——复制当前进程创建子进程，**一次调用、两次返回**（父进程返回子进程 PID，子进程返回 0）；**execve**——在**当前进程**上下文中加载并运行新程序（替换进程映像，**不创建**新进程）；**lseek**——调整文件当前读写位置。

**考试答题**：单选配对题（2024.4 单选 7、10；2024.10 单选 7）："创建子进程"→fork；"加载运行新程序"→execve；"调整读写位置"→lseek。填空"进程是____的一次运行过程"→ 程序（2024.10 填空 19）。易错：execve 不产生新 PID。

### 第 5 章 程序的存储访问（cache 大题章）

#### 5.1 存储元件与存储器分类 ★★★

**定义详解**：存储元件三种材料：**半导体器件、磁（性）材料、光介质**（2026.4 填空 18）。按断电后信息是否丢失分：**易失性**（RAM：SRAM、DRAM，即主存/cache）与**非易失性**（ROM、磁表面、光盘）。按存取方式分：随机存取（RAM/半导体 ROM）、顺序存取（磁带）、直接存取（磁盘）。

**考试答题**：名词解释"易失性存储器"（2026.4 名词解释 22，5 分）= 定义（断电信息丢失）+ 举例（SRAM/DRAM/主存）+ 对比（ROM/磁/光非易失）。单选"属于易失性存储器"→ RAM/主存（2024.4 单选 8、2024.10 单选 8 连考，选项换了但答案同类）。易错：ROM 中可改写的（EEPROM/Flash）依然算非易失。

#### 5.2 存储层次结构 ★★★

**定义详解**：层次自上而下：**寄存器 → cache（SRAM）→ 主存（DRAM）→ 磁盘 → 磁带/光盘**。规律：越往上**速度越快、容量越小、位价越高**。建立层次结构的依据是**程序访问的局部性原理**（时间局部性+空间局部性）——刚被访问过的项及其邻居很快还会被访问，所以把常用数据放上层。

**考试答题**：填空"层次结构存储系统在____、____和价格方面折中"→ 速度、容量（2024.10 填空 18）。单选"存取时间最小的存储器"→ 层次顶端：cache（有寄存器选项则选寄存器）（2025.4 单选 8）。

#### 5.3 SRAM 与 DRAM ★★

**定义详解**：SRAM（静态 RAM）：**触发器**存储信息，只要不断电信息不丢、**无需刷新**，快、贵、密度低 → 做 **cache**；DRAM（动态 RAM）：**电容**存储信息，电容会漏电、需**定时刷新**，慢、便宜、密度高 → 做**主存**。

**考试答题**：单选/填空配对：cache—SRAM—触发器—不刷新；主存—DRAM—电容—刷新。易错：**DRAM 刷新 ≠ cache 替换**，两回事。

#### 5.4 磁盘存取与存取时间 ★★

**定义详解**：磁盘读写定位三阶段：**寻道时间**（磁头移动到目标磁道）+ **旋转等待时间**（目标扇区转到磁头下，平均半转）+ **数据传输时间**。

**考试答题**：单选"磁盘读写不包括的操作"→ 排除三阶段之外的选项（2024.4 单选 9）。计算题可能给转速求平均旋转等待：7200 转/分 → 一转 60/7200 s ≈ 8.33ms → 平均等待 ≈ 4.17ms（半转）。寻道与旋转等待是两个独立动作，别合并。

#### 5.5 cache 三种映射方式与地址划分 ★★★（分析/计算题必考）

**定义详解**：cache—主存以**块**为单位交换信息（2026.4 单选 8）。主存地址按映射方式切分：
| 映射方式 | 主存地址结构 | 去向约束 | Tag 比较次数 |
|---|---|---|---|
| 直接映射 | Tag + **行号** + 块内地址 | 每块只能去**唯一固定**行（行号=块号 mod 行数） | 1 次 |
| 全相联 | Tag + 块内地址（**无行号**） | 任意块可放**任意**行 | 全部行 |
| 组相联 | Tag + **组号** + 块内地址 | 组间直接（组号固定）、**组内全相联** | 组内所有行 |

**考试答题**：大题固定三问——地址字段划分 / cache 总容量 / 命中率或比较次数（2024.10 分析题 30 全相联、直接映射题各一道；2026.4 计算题 27 组相联 9 分）。写"映射特征"一句话：直接映射"一对一、冲突率高但硬件简单"；全相联"任意放、利用率高但比较器贵"；组相联"折中"。

**计算方法**（六步模板，配合 2026.4 计算题 27 算例：主存 64MB、cache 数据区 4KB、4 路组相联、块 64B）：
1. 主存地址位数 = log₂(主存容量) = log₂64MB = **26 位**；
2. 块内地址位数 = log₂(块大小) = log₂64B = **6 位**；
3. cache 行数 = 数据区容量 ÷ 块大小 = 4KB ÷ 64B = **64 行**；
4. 组数 = 行数 ÷ 路数 = 64 ÷ 4 = **16 组** → 组号 log₂16 = **4 位**；
5. Tag 位数 = 26 − 4 − 6 = **16 位** → 地址结构 `Tag(16) | 组号(4) | 块内(6)`；
6. cache 总容量 = 行数 × 每行总位数，每行 = 数据位(64×8=512) + Tag(16) + 有效位(1) + 脏位(1，回写法才有；若计 LRU，4 路组内每行再加 2 位) = 530 位 → 总容量 = 64×530 = **33920 位**。

（直接映射时第 4 步换成：行号位数 = log₂(行数)；全相联：无行号字段，Tag = 主存位数 − 块内位数。）

#### 5.6 命中率与平均访问时间 ★★★

**定义详解**：命中率 H = 命中次数 ÷ 访问总次数（N 命中 + N 缺失）。**平均访问时间 = H×t_cache + (1−H)×t_主存**。

**考试答题**：分析题末问常考（2024.10 分析题 30）。计算例：命中 1900 次、缺失 100 次 → H = 1900/2000 = 95%；t_cache=10ns、t_主存=100ns → 平均 = 0.95×10 + 0.05×100 = 9.5+5 = **14.5ns**。⚠️ 别把 (1−H) 写成 H；缺失后的时间按整个主存访问算（不命中才去主存）。

#### 5.7 虚拟存储与页式地址转换 ★★★

**定义详解**：虚拟存储用磁盘扩充主存逻辑容量——程序用**虚拟地址**编程，运行时由硬件(MMU)+OS 转换为物理地址；同时解决**主存容量受限**与**程序重定位**两个问题（2024.10 填空 17）。管理方式：**页式**（等长页、碎片少内耗、无逻辑分段）、**段式**（按逻辑划分、易共享保护、有外部碎片）、**段页式**（先分段再分页，现代 OS 实际主流，2025.4 单选 10）。

**考试答题**：单选"现代 OS 主要采用"→ **段页式**。计算题：虚拟地址 = **页号 + 页内偏移**（页 4KB → 页内 12 位；虚拟 64MB → 页号 14 位）；物理地址 = **页帧号 + 页内偏移**（偏移照抄，页号查页表替换）。虚拟地址空间分为**操作系统内核区与用户程序存储空间**两大部分=内核空间/用户空间（2026.4 填空 19）。

### 第 6 章 程序中的 I/O 操作实现

#### 6.1 I/O 子系统层次 ★★★

**定义详解**：自上而下两层八级：**用户空间 I/O 软件**（运行时系统：库函数等 I/O 封装）→ 内核空间：**文件系统 → 与设备无关的 I/O 软件（设备命名/保护/缓冲/差错处理）→ 设备驱动程序 → 中断服务程序（最底层）** → I/O 硬件。层次化的目的：设备无关性、统一接口、便于维护。

**考试答题**：单选"不属于内核空间 I/O 软件的是"→ **运行时系统**（它在用户空间，2026.4 单选 10）；"与设备无关的 I/O 软件**不含**"→ **中断服务程序**（它与硬件强相关，属最底层，2024.10 单选 9）。填空"内核空间 I/O 软件由____组成"→ 设备驱动程序、中断服务程序（+文件系统）（2024.10 填空 16）。两级辨析题眼：看到"运行时系统/库函数"选用户空间；看到"中断服务"选最底层。

#### 6.2 系统调用及其开销 ★★★

**定义详解**：系统调用是用户程序请求内核服务的接口（打开/读/写/关闭文件等）。开销高的原因：①**用户态↔内核态切换**（陷入 trap 与返回）；②**保存/恢复现场**（寄存器上下文）；③参数与结果在**用户/内核空间之间拷贝**；④破坏 **Cache/TLB 局部性**（缓存污染）；⑤内核内还有系统调用处理程序→服务例程的间接分发。

**考试答题**：简答按上述五点分条写（跨考期高频简答）。易错：库函数（printf）本身在**用户态**执行，内部用到系统调用时才陷内核；系统调用开销 ≠ 函数调用开销（后者无模式切换）。

#### 6.3 程序直接控制 I/O（轮询） ★★

**定义详解**：最原始方式：CPU 执行 I/O 指令启动设备后，**反复读取设备状态寄存器查询是否就绪**（轮询/忙等），就绪后在 CPU 控制下传送数据。CPU 与设备串行工作。

**考试答题**：简答模板（2026.4 简答 25）：①CPU 启动设备并**反复查询状态**；②就绪后由 CPU 传送一个字/字节；③缺点——CPU 忙等、与设备串行、利用率低；④适用——CPU 不忙、设备较快或实时性要求高的场景。答题必须写"忙等/查询状态"这个关键词。

#### 6.4 中断控制 I/O 与中断服务三阶段 ★★★

**定义详解**：CPU 启动设备后**不再等待**、继续执行程序；设备就绪时经中断请求线向 CPU 发**中断请求**；CPU 在每条指令执行结束时检查中断，响应后：**准备阶段**（关中断、保存断点和现场）→ **处理阶段**（执行中断服务程序完成数据传送）→ **恢复阶段**（恢复现场与断点、开中断、返回）。三阶段名称填空连考（2026.4 填空 20）。

**考试答题**：简答"基本思想"四点（2024.10 简答 26）：①启动后 CPU 不等待（并行工作）②就绪发中断请求 ③响应后保护现场→中断服务→恢复现场 ④对比程序直接控制消除了忙等。辨析：**内部异常**（缺页、非法操作码、除 0——来自 CPU 内部，2025.4 单选 7）≠ **外部中断**（I/O 完成、时钟——来自外设）。

#### 6.5 DMA 与主机占用率计算 ★★★

**定义详解**：DMA（直接存储器存取）：设备与主存之间开辟**直接数据通路**，由 **DMA 控制器**控制整块数据的传送，CPU 只在传送**前**（初始化/预处理）和传送**结束**（中断处理）介入，传送期间 CPU 可继续执行其他程序。适合磁盘等**成块、高速**传送。

**考试答题**：简答"DMA 优点"——CPU 介入极少、无逐字传送的指令级开销、成块传送效率高；注意 DMA 预处理/后处理仍需 CPU。分析题考"中断方式 vs DMA 方式的主机占用率"（2026.4 分析题 29）。

**计算方法**（中断方式占用率四步，例：缓冲器 16B、磁盘 4MB/s、每次中断开销 500 周期、主频 500MHz）：
1. 每次传送的数据量引发一次中断 → 中断时间间隔 = 16B ÷ 4MB/s = **4μs**；
2. 每次中断开销 = 500 周期 ÷ 500MHz = **1μs**；
3. 磁盘连续传输时主机占用率 = 1μs ÷ 4μs = **25%**；
4. 若磁盘仅 5% 时间在传输 → 平均占用率 = 25% × 5% = **1.25%**。
口诀："开销时间 ÷ 间隔时间 = 占用率"。若改用 DMA：只需按块传送结束后一次中断，占用率骤降——这正是 DMA 的意义。

#### 6.6 流缓冲区与 I/O 端口编址 ★★

**定义详解**：标准库流缓冲三种属性：**全缓冲**（缓冲区满才刷新，普通文件）、**行缓冲**（遇换行刷新，终端 stdin/stdout）、**无缓冲**（立即写，stderr）。I/O 端口编址两种：**独立编址**（I/O 地址空间独立，需专用 I/O 指令 IN/OUT）、**统一编址**（存储器映射 I/O，端口占主存地址，用访存指令即可访问，无需专用指令）。

**考试答题**：单选"普通文件缓冲属性"→ **全缓冲**（2024.10 单选 10）；填空三属性名默写（2024.10 填空相关）。易错：终端是**行缓冲**不是全缓冲。统一/独立编址考名词解释或单选，抓题眼"是否占用主存地址空间"。

#### 简答题（第 23~26 题，每题 5 分）

**23. 简述计算机系统基本性能指标和 CPU 的性能指标。**
> 【推导答案要点】
> - 机器基本性能指标：机器字长（一次能处理的二进制位数）、主频、存储容量、运算速度等；
> - CPU 性能指标：主频（时钟频率）、CPI（执行一条指令的平均时钟周期数）、MIPS（每秒执行百万条指令数）、程序执行时间（CPU 时间 = 指令条数 × CPI ÷ 主频）；
> - 点题：性能由三者共同决定，不能只看主频。

**24. 简述原码补码运算过程。**
> 【推导答案要点】
> - 原码加减：符号位与数值位分开处理。同号相加数值位相加、符号不变；异号相减转为加负数的补…（实际按教材口径：异号相加时先比较绝对值大小，用大数减小数，符号取绝对值大的操作数符号）；
> - 补码加减：符号位与数值位**一起**按模 2ⁿ 运算；减法化为加法（加 [−y]补 = 对 y 补码取反加一）；最高位进位自然丢弃；
> - 结论：补码把减法统一为加法、简化运算器线路，故机器中整数普遍用补码表示。

**25. 简述程序直接控制 I/O 方式的基本思想。**
> 【推导答案要点】
> - CPU 直接执行 I/O 指令启动设备，并**反复查询（轮询）设备状态**；
> - 查到"就绪"后才在 CPU 控制下传送一个字/字节的数据；
> - 缺点：CPU 与设备串行工作、忙等（查询期间不能做其他事），CPU 利用率低；适合设备快、CPU 不忙的场景。

**26. 简述静态链接和动态链接的差别。**
> 【推导答案要点】
> - 链接时机：静态在**链接时**一次性完成；动态推迟到**加载时或运行时**；
> - 库代码：静态把库代码复制进可执行文件（文件大、每个进程各带一份）；动态只在引用处记录信息、运行时映射共享库（内存中一份库代码多进程共享）；
> - 更新维护：静态库升级须重新链接所有程序；动态库替换文件即可生效；
> - 开销：动态链接有加载/运行时地址绑定的额外开销。

#### 计算题（第 27~28 题，每题 9 分）

**27.** 主存地址空间 64MB，按字节编址；cache 数据区 4KB，4 路组相联，LRU + 回写，块大小 64B。
- （1）主存地址字段如何划分？（2）cache 总容量多少位？

> 【推导答案】
> ① 主存 64MB=2²⁶B → 主存地址 26 位；块 64B → 块内地址 6 位；
> ② cache 行数 = 4KB ÷ 64B = 64 行；4 路组相联 → 组数 = 64 ÷ 4 = 16 组 → 组索引 4 位；
> ③ Tag = 26 − 4 − 6 = **16 位**。地址划分：`Tag(16) | 组号(4) | 块内地址(6)`；
> ④ 总容量 = 每行（数据 64×8=512 位 + Tag 16 位 + 有效位 1 位 + 脏位 1 位）= 530 位 × 64 行 = **33920 位**（回写方式需脏位；若计入 LRU 替换信息，4 路组内每行还需 2 位，共再加 128 位）。

**28.** 两个指令序列 S1/S2 在 500MHz 机器上运行，指令分 A、B、C、D 四类，CPI 及条数如题 28 表。求：(1) 各有多少条指令；(2) 各自 CPI；(3) 时钟周期数；(4) 执行时间。

> ⚠️ 扫描图中"各指令的 CPI"一行的数值模糊，A/B/C/D 各自的 CPI【待核实】。可辨识数据：S1 条数（A~D）= 1、2、3、4；S2 条数（A~D）= 5、2、2、1。
> 【解题模板】①N = Σ条数ᵢ；②CPI = Σ(条数ᵢ×CPIᵢ) ÷ N；③周期数 = Σ(条数ᵢ×CPIᵢ)；④执行时间 = 周期数 ÷ 500MHz（周期数 × 2ns）。与 2024.10 第 27 题（同型 CPI 题）共用此模板。

#### 分析设计题（第 29~30 题，每题 6 分）

**29.** 处理器主频执行（图中数字为 5000MHz【待核实，教材同型例题为 500MHz】）；磁盘控制器有 16B 数据缓冲器，磁盘传输速率 4MB/s；若用中断方式，每次传送开销 500 个时钟周期；磁盘只用 5% 的时间传输。求主机占用率。

> 【推导答案】
> ① 每次传送 16B，中断间隔 = 16B ÷ 4MB/s = 4μs；
> ② 每次中断开销 = 500 周期 ÷ 500MHz = 1μs（若按 5000MHz 则为 0.1μs）；
> ③ 磁盘连续传输时主机占用率 = 1μs ÷ 4μs = **25%**（5000MHz 则为 2.5%）；
> ④ 仅 5% 时间传输 → 平均占用率 = 25% × 5% = **1.25%**（5000MHz 则为 0.125%）。

**30.** C 程序含 main.c（`int buf[2]={1,2}; extern void swap(); int main(){ swap(); return 0; }`）与 swap.c（`extern int buf[]; int *bufp0=&buf[0]; int *bufp1; void swap(){ int temp; bufp1=&buf[1]; temp=*bufp0; *bufp0=*bufp1; *bufp1=temp; }`）。问 main.o 与 swap.o 符号表中的全局符号、外部符号。
> 【推导答案】
> - **main.o**：全局符号（本模块定义）= `buf`、`main`；外部符号（本模块引用、他处定义）= `swap`；
> - **swap.o**：全局符号 = `bufp0`、`bufp1`、`swap`；外部符号 = `buf`。
> 解析：定义的非静态全局变量与函数名是全局符号（定义者）；`extern` 声明且未在本模块定义的是外部符号（引用者）。

#### 简答题（第 23~26 题）

**23. 简述在递归深度较深时，递归调用的时间开销和空间开销。**
> 【推导答案要点】
> - 空间：每次调用压入一个栈帧（返回地址、保存的寄存器、参数、局部变量），空间开销随递归深度线性增长，过深会**栈溢出**；
> - 时间：每次调用/返回都有 call/ret 指令开销、栈帧建立与拆除、参数压栈；且破坏 Cache 局部性；
> - 结论：深度为 n 的递归，额外空间 O(n)、额外时间 O(n)（相对迭代版多 n 次调用返回开销）。

**24. 简述计算机内部和外部需要进行数制转换的原因。**
> 【推导答案要点】
> - 内部用二进制：器件只有两个稳定状态（高低电平），二进制易于物理实现、运算规则简单、抗干扰可靠；
> - 外部（人机交互）用十进制/十六进制：人类习惯十进制；二进制太长不易读，十六进制是二进制的紧凑缩写（每 4 位二进制对应 1 位十六进制）；
> - 所以输入输出、显示、地址表示时常需在二/十六/十进制间转换。

**25. 简述动态链接的共享性和动态性。**
> 【推导答案要点】
> - 共享性：动态库（共享库）在内存中只保留一份代码，多个进程可共享同一副本，节省内存和磁盘空间；库升级时替换库文件即可，无需重新链接各个程序；
> - 动态性：链接时机推迟到**加载时或运行时**，在程序加载/调用处才把共享库映射进来并完成符号绑定（地址重定位），甚至可在运行时按需装入（延迟绑定）。

**26. 简述中断控制 I/O 方式的基本思想。**
> 【推导答案要点】
> - CPU 启动 I/O 后**不等待**，继续执行其他程序（程序并行）；
> - 设备完成（或就绪）时通过中断请求线向 CPU 发**中断请求**；
> - CPU 响应后：保存断点和现场 → 执行**中断服务程序**完成数据传送 → 恢复现场返回被中断程序；
> - 与程序直接控制方式相比，CPU 无需反复查询设备状态（消除忙等），效率提高。

> 【推导解题模板】①把十六进制写成 16 位二进制；②识别为补码时最高位为符号位；③按补码加减规则运算（减法转加 [−y]补=取反加一）；④判断溢出：同号相加结果变号 → 溢出（或双符号位法）；⑤CF=最高位进位（加法），OF=符号位进位⊕次高位进位。同型真题详解见 [计算机系统原理13015【数据的表示与运算】](https://blog.csdn.net/qq_23872947/article/details/137093142)（含 x=−68、y=80 的 CF/OF 完整算例）

**30.【分析题】** 假定 cache 采用全相联方式，主存块大小为 64B……（cache 映射型）
> 【推导解题模板】①块内地址位数 = log₂64 = 6 位；②全相联：主存地址 = Tag + 块内地址（无行号字段），任意主存块可放入任意 cache 行；③比较次数 = cache 行数（全相联需与**所有**行的 Tag 比较）；④命中率/平均访问时间 = H×t_cache+(1−H)×t_主存。对照直接映射题（第 3.2 节推荐预览第 1 题）：主存地址 = Tag + 行号 + 块内地址，行号 = log₂(cache 行数)。

### 3.4 2024 年 4 月考期（前 15 题选项完整）

**来源**：[考生网 paper-120992](https://www.zikaosw.cn/kaoshi/paper-120992.html)（试卷元数据：30 题）

#### 单项选择题（第 1~10 题；每题分值按 2026.04 原件推定为 2 分【待核实】）

**1. 完整的计算机系统应包括**
- A. 运算器、存储器、控制器　B. **硬件和软件**　C. 主机和实用程序　D. 外部设备和主机
- 【推导答案】B。解析：计算机系统=硬件系统+软件系统；A 只是硬件的一部分。

**2. 某数在计算机中用 8421BCD 码表示为 0111 1000 1001，其真值为**
- A. **789**　B. 789H　C. 1929　D. 11110001001B
- 【推导答案】A。解析：0111→7，1000→8，1001→9，即十进制 789。切勿按二进制权值展开（那是 D 的错误来源）。

**3. 下列不属于翻译程序种类的是**
- A. 汇编程序　B. 解释程序　C. 编译程序　D. **链接程序**
- 【推导答案】D。解析：翻译程序=汇编程序、编译程序、解释程序；链接是"组合目标文件"，不翻译语言。

**4. 下列说法中不正确的是**
- A. 任何可以由软件实现的操作也可以由硬件来实现
- B. 固件就功能而言类似于软件，而从形态来说又类似于硬件
- C. 在计算机系统的层次结构中，指令集体系结构属于硬件级
- D. **面向高级语言程序设计的机器是完全可以实现的**
- 【推导答案】D
- 解析：A 对——软硬件在逻辑功能上等价（软硬件逻辑等价性）；B 对——固件=固化在 ROM 中的微程序；C 对——ISA 是软硬件交界面、划入硬件（机器语言）级；D 错——直接面向高级语言的机器效率低、缺乏实用性，并非"完全可以实现"的合理表述。

**5. 介于计算机硬件与应用程序之间，包括为有效、安全地使用和管理计算机以及为开发和运行应用软件而提供的各种软件，称为**
- A. 应用软件　B. **系统软件**　C. 操作软件　D. 用户软件
- 【推导答案】B。解析：这是教材中系统软件的定义；OS 是系统软件的核心。

**6. 用来将若干可重定位目标文件组合起来，生成一个可执行目标文件的过程称为**
- A. 预处理　B. 编译　C. 汇编　D. **链接**
- 【推导答案】D。解析：抓题眼"可重定位目标文件→可执行目标文件"，这是链接的定义。

**7. 在当前进程的上下文中加载并运行一个新程序，用到的函数是**
- A. main　B. fork　C. **execve**　D. add
- 【推导答案】C。解析：fork=创建子进程；execve=替换当前进程映像、加载新程序。

**8. 属于易失性存储器的是**
- A. **随机存取存储器**　B. 只读存储器　C. 磁表面存储器　D. 光存储器
- 【推导答案】A。

**9. 磁盘读/写操作不包括**
- A. 寻址操作　B. 寻道操作　C. 旋转等待操作　D. **读/写申请操作**
- 【推导答案】D【待核实】
- 解析：磁盘一次读写 = 寻道（磁头移到目标磁道，即"寻址"）+ 旋转等待（等目标扇区转到磁头下）+ 数据读写传输三个阶段；"读/写申请"不属于磁头动作本身。（A 与 B 在部分教材表述中均视为寻道环节，此处按三阶段排除 D。）

**10. 需要调整文件的当前读/写位置，用到的函数是**
- A. open　B. stat　C. **lseek**　D. write
- 【推导答案】C。解析：open 打开、stat 取文件元数据、write 写、lseek 定位读写偏移。

### 逐个击破：典型题 + 易错警示

**① 浮点加减四步骤**（典型题：2024.10 填空 14）
- 必背口诀：**对阶 → 尾数加减 → 规格化 → 舍入**。
- ⚠️ 易错：对阶时"**小阶向大阶**"（小阶尾数右移）；写"大阶向小阶"直接 0 分。规格化有左规、右规两个方向。

**② 溢出与补码**（典型题：2024.10 分析题 R[ax]=FFFAH）
- ⚠️ 易错一：把"最高位产生进位被丢弃"当作溢出。进位丢弃是补码模运算的正常现象，溢出只看**同号相加（或异号相减）结果符号是否改变**。
- ⚠️ 易错二：CF 与 OF 混淆。CF=无符号借位/进位，OF=带符号溢出，两者独立。

**③ cache 映射**（典型题：2024.10 分析题 64B 全相联）
- 做题三步：块内地址位数（64B→6 位）→ 按映射方式切分主存地址字段 → 算 Tag 位数/比较次数/命中率。
- ⚠️ 易错：全相联地址中**没有行号字段**、需与所有行比较；直接映射每块只能去固定行。组相联 = 组间直接 + 组内全相联。

**④ 冯·诺依曼结构**（典型题：2024.10 单选 2）
- ⚠️ 易错："基本特点"答"存储程序"，不是列五大部件；五大部件是填空题答法（运算器/控制器/存储器/输入/输出）。

**⑤ 四步骤与链接**（典型题：2024.10 单选 6/2024.4 单选 3）
- ⚠️ 易错：链接程序**不是**翻译程序；第一步是**预处理**不是编译；动态链接"共享性、动态性"简答要分开写两点。

**⑥ 中断控制 I/O**（典型题：2024.10 简答 26）
- 得分点：①启动后 CPU 不等待（并行）②设备就绪发中断请求 ③保护现场→中断服务→恢复现场 ④对比程序直接控制消除忙等。
- ⚠️ 易错：内部异常（缺页、非法操作码、除 0）≠ 外部中断（I/O、时钟）。

**⑦ 存储层次**（典型题：2024.10 单选 8）
- ⚠️ 易错：主存、cache 都是 RAM 都易失；ROM 中也有"可改写"的（EEPROM/Flash），但依然算非易失。"存取时间最小"= 层次最顶端。

**⑧ 汇编与寄存器**（典型题：2024.4 填空 11/2025.4 单选 4）
- ⚠️ 易错：机器指令（二进制）↔ 汇编指令（符号）一一对应；SP/PC/Flag 是**专用**寄存器，别选进"通用寄存器"。Intel 与 AT&T 格式：**操作数顺序相反**，AT&T 寄存器加 %、立即数加 $。

**⑨ fork/execve/lseek**（典型题：2024.4 单选 7、10）
- ⚠️ 易错：fork 创建子进程（一次调用、两次返回）；execve **不创建**新进程，是替换当前进程映像。

**⑩ 进制与 BCD**（典型题：2024.4 单选 2、每卷第 1 题）
- ⚠️ 易错：BCD 码**每 4 位一组对应 1 位十进制**，0111 1000 1001 是 789，而按二进制权值展开是 1929（正是本题 C 选项干扰项）；进制比较题先统一进制再比。
